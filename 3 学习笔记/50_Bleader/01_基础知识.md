# Blender 基础知识

> [!summary]
> 默认布局下，先会转视角、切视图，再动物体。视图数字键在**小键盘**上。一条作品的基本流程是：建模 → 布光 → 材质 → 渲染。

## 1. 视角控制

鼠标对着 3D 视口操作。

| 操作 | 快捷键 |
| --- | --- |
| 旋转视角 | 按住中键拖动 |
| 平移视角 | `Shift` + 中键拖动 |
| 推近 / 拉远 | 滚动中键滚轮 |

## 2. 视图切换

数字键默认走**小键盘**。没有小键盘时，可在偏好设置里打开 *Emulate Numpad*。

| 操作 | 快捷键 |
| --- | --- |
| 顶视图 / 底视图 | `7` / `Ctrl + 7` |
| 前视图 / 后视图 | `1` / `Ctrl + 1` |
| 右视图 / 左视图 | `3` / `Ctrl + 3` |
| 反转当前视图 | `9` |
| 摄像机视角 | `0` |
| 透视 ⇄ 正交 | `5` |
| 上下左右微调 | `8` `2` `4` `6` |
| 缩放微调 | `+` / `-` |

## 3. 物体控制

| 操作 | 快捷键 |
| --- | --- |
| 移动 | `G` |
| 旋转 | `R` |
| 缩放 | `S` |
| 恢复位移 / 旋转 / 缩放 | `Alt + G` / `Alt + R` / `Alt + S` |
| 新建 | `Shift + A` |
| 复制 | `Shift + D` |
| 删除 | `X` 或 `Delete` |
| 隐藏选中 | `H` |
| 隐藏未选中 | `Shift + H` |
| 显示全部隐藏物体 | `Alt + H` |

## 4. 选择

| 操作 | 快捷键 |
| --- | --- |
| 全选 / 取消全选 | `A` |
| 刷选（圆形选择） | `C`，滚轮改笔刷大小，右键或 `Esc` 退出 |
| 加选 / 减选 | 按住 `Shift` 点选 |

## 5. 基本流程

建模 → 布光 → 材质 → 渲染

## 6. 3D 游标

游标用来定位，也可以当作变换的轴心点。

| 操作 | 快捷键 |
| --- | --- |
| 调用游标 Pie 菜单 | `Shift + S` |
| 游标回到世界中心 | `Shift + C` |
| 移动游标 | 游标工具，或 `Shift` + 右键 |

## 7. 窗口

窗口面板可以拆分，也可以互换位置。

| 操作 | 快捷键 |
| --- | --- |
| 最大化当前窗口 | `Ctrl + 空格` |

## 8. 移动时的吸附与轴向

进入 `G` 移动之后：

| 操作 | 做法 |
| --- | --- |
| 按方格增量吸附 | 按住 `Ctrl` |
| 约束到全局轴 | 按一次 `X` / `Y` / `Z` |
| 改到物体局部轴 | 再按一次同一个轴键 |

## 9. 原点

每个物体都有原点。在 3D 世界里，原点是计算机存放这个物体信息的数据点。
