# Blender 基础知识

> [!summary]
> 默认布局下，先会转视角、切视图，再动物体。视图数字键在**小键盘**上。

## 1. 视角控制

鼠标对着 3D 视口操作。

| 操作 | 快捷键 |
| --- | --- |
| 旋转视角 | 按住中键拖动 |
| 平移视角 | `Shift` + 中键拖动 |
| 推近 / 拉远 | 滚动中键滚轮 |

## 2. 视图切换

数字键默认走**小键盘**。没有小键盘时，可在偏好设置里打开 *Emulate Numpad*。

| 操作 | 快捷键 |
| --- | --- |
| 顶视图 / 底视图 | `7` / `Ctrl + 7` |
| 前视图 / 后视图 | `1` / `Ctrl + 1` |
| 右视图 / 左视图 | `3` / `Ctrl + 3` |
| 反转当前视图 | `9` |
| 摄像机视角 | `0` |
| 透视 ⇄ 正交 | `5` |
| 上下左右微调 | `8` `2` `4` `6` |
| 缩放微调 | `+` / `-` |

## 3. 物体控制

| 操作 | 快捷键 |
| --- | --- |
| 移动 | `G` |
| 旋转 | `R` |
| 缩放 | `S` |
| 恢复位移 / 旋转 / 缩放 | `Alt + G` / `Alt + R` / `Alt + S` |
| 新建 | `Shift + A` |
| 复制 | `Shift + D` |
| 删除 | `X` 或 `Delete` |
| 隐藏选中 | `H` |
| 隐藏未选中 | `Shift + H` |
| 显示全部隐藏物体 | `Alt + H` |

## 4. 选择

| 操作 | 快捷键 |
| --- | --- |
| 全选 / 取消全选 | `A` |
| 刷选（圆形选择） | `C`，滚轮改笔刷大小，右键或 `Esc` 退出 |
| 加选 / 减选 | 按住 `Shift` 点选 |
