# 4. 窗口、导航与快捷键

认四个面板，会摆窗口，会飞镜头，会用 W / E / R 改物体。

## 四个面板

| 面板 | 在哪 | 干什么 |
| --- | --- | --- |
| 放置 Actor | 左侧 | 把形状、灯光、自己的蓝图拖进场景 |
| 世界大纲 | 右侧 | 关卡里所有对象的列表 |
| 细节 | 选中后出现 | 改位置、旋转、缩放、网格、材质 |
| 内容浏览器 | 底部 | 项目里的资产：网格、材质、道具、粒子 |

大纲里可以建文件夹归类。选中文件夹或按住多选，就能一起隐藏、移动，不用一个个点。

细节里改数字，视口里的物体会跟着变。缩放旁边的锁打开后是等比缩放。想换模型、保留原来的位置和大小：在细节里换网格体。换材质同理。撤销是 `Ctrl + Z`。

内容浏览器里，初学者内容包适合拿来试手。道具文件夹里的网格直接拖进场景。不想它缩回去，点 **停靠到布局**。

## 窗口布局

面板可以拖出来变成独立窗口，也能拖到屏幕任意一边重新停靠，关掉也行。

- 找回某个窗口：顶部 **窗口** 菜单。
- 同一个窗口可以开多份。
- 布局乱了：**窗口 → 加载布局 → 默认编辑器布局**。
- `Ctrl + 空格`：把内容浏览器、细节、大纲叫回来。

放置 Actor 是 UE4 那套经典布局里的。UE5 默认不一定有它，常用形状在快速添加里也能放进场景。

## 吸附

移动时一格一格跳，是因为吸附开着。

- 数值大（比如 100）：跳得远，方便粗对齐。
- 设成 1：更顺。
- 关掉：自由移动。

常用 1 或 10，场景不容易摆歪。旋转、缩放也有各自的吸附。

## 视口和播放

视口左上角三条横线是视口选项。里面的 **屏幕百分比** 决定画多清楚：

- 调低（如 25）：变糊，用来预览低分辨率。
- **100**：日常用这个。
- 调高（如 200）：更清楚，更吃性能。

进入游戏：点播放，或 `Alt + P`。第三人称模板里用 WASD 走、空格跳。退出播放用 `Esc`。

地形、植被、建模这些模式以后再讲，先知道顶栏能切换。

## 镜头和变换

**飞镜头**：按住鼠标右键再按键。

| 键 | 作用 |
| --- | --- |
| W A S D | 前后左右 |
| Q / E | 下降 / 上升 |
| 滚轮 | 加快或减慢飞行速度 |

松手后，Q / E / R / W 变成变换工具，和飞行时不是同一套。

| 键 | 作用 |
| --- | --- |
| W | 移动。拖箭头沿轴走，拖中心圆可在空间里自由拖 |
| E | 旋转 |
| R | 缩放 |
| Q | 只选择，隐藏操纵杆，避免误碰物体 |

顶栏对应图标和这些键是一样的。

# 5. 操作物体

在上一节的移动、旋转、缩放之上，加上复制、跟着走，以及换模型、换材质。

## 复制和镜头跟随

先选中物体，再按住修饰键拖操纵器。

| 操作 | 结果 |
| --- | --- |
| `Alt` + 拖动 | 复制一个 |
| `Shift` + 点击 | 多选。多选后再 `Alt` + 拖动，会一起复制 |
| `Shift` + 拖动 | 不复制，摄像机会跟着物体走 |
| `Shift` + `Alt` + 拖动 | 复制，并且摄像机跟着新副本走 |

多选后旋转，会绕**最后选中**的那个转。操纵器停在谁身上，就是绕谁转。

## 换网格和换材质

想换模型、保留原来的位置和变换：在细节面板的静态网格体里换。

两种换法：

- 在细节里直接搜索、点选。
- 内容浏览器里先点中目标资产，再点细节面板里的**箭头**，当前物体就换成浏览器里选中的那个。

网格、材质，以及其他能从内容浏览器指定的资产，都可以用这个箭头。

找不到资产在哪：点网格或材质旁边的定位图标，会跳到内容浏览器里的文件夹。初学者内容包的道具一般在 `Content/StarterContent/Props`。

换材质还有两种：从列表里选，或直接把材质拖到物体上。刚换上时可能要等着色器编译。

## 数值框可以算式

缩放旁边的锁：没锁只沿一个轴变，锁上是等比。

数值不用先心算。在输入框里直接写运算，引擎会算出结果，细节面板以外的数值框大多也行。

- `1+0.5`：在当前值上加
- `*2`：变成两倍
- 除法同样可以写

细节面板里还有不少选项，这节先不用记。

## 练习

打开初学者内容包的 Props，拖几个静态网格进场景，搭一小块布景。用来练复制、多选旋转、换模型和换材质。

# 6. 整理场景

一组要一起搬的物体用编组。大纲里只是想归类、好找，用文件夹。两件事不要混。

## 编组

`Shift` 点选要放在一起的物体，再 `Ctrl + G`。之后点一个就是整组，移动也是整组。

| 操作 | 结果 |
| --- | --- |
| `Ctrl + G` | 编组 |
| `Shift + G` | 取消编组 |

右键菜单里的 **组**，以及大纲里的组 Actor，和这两个快捷键是一样的。

只想挪组里的某一个、又不想拆开再重编：关掉 **允许组选择**。它们还是一组，但可以单独选、单独移。改完再打开，就恢复成整组选中。组里物体很多时用这个，比反复拆组合算。

## 文件夹

大纲右上角带加号的文件夹图标用来新建文件夹。创建时如果已经选中物体，它们会自动进这个文件夹，也可以之后再拖进去。文件夹里还能再建子文件夹。

文件夹只负责在大纲里归类。同一文件夹里的物体，不会因此变成一组。编组 Actor 可以再拖进某个子文件夹，旁边没编进去的物体仍然是单独的。

## 练习

把上一节搭的小布景整理一遍：该编组的编组，其余放进文件夹，让大纲能直接点到想要的东西。

# 7. 建模工具

关卡里的占位块可以直接在虚幻里做，不必先去别的软件。这节只做白模，颜色和光照以后再改。

## 打开插件

虚幻 5.4 里更多建模工具要手动开：**编辑 → 插件**，搜索 `modeling`。两个都启用：

- Modeling Tools Editor Mode
- Static Mesh Editor Modeling Mode

都还是 Beta。启用后按提示重启。然后从顶栏进入 **建模** 模式。插件里内置的、商城里的、自己装的都在这一页，用搜索找，不用逐个翻。

## 拉一个盒子

选盒子。矩形只是一个平面，做墙体用处不大。

- 宽高默认滑条是 1 到 1000，可以手打更大的数。课上先设 500，再挪位置、拉大，厚度改成 20。
- 细分能让模型更细，做原型可以不提。
- 输出类型选 **静态网格体**。材质可以现在指定，也可以以后再换。
- 必须点 **接受**，网格才会真正生成。取消会丢掉还没接受的修改。

生成的网格在内容浏览器的 Generated 文件夹里。选中物体，用旁边的定位图标就能跳过去。不用的记着删，免得堆一堆临时模型。

## 在同一块网格上挤出

这样做出来的是**一整块网格**，不是几片分开的平面。要在侧面加墙，就改这一块，不要再各拉一个盒子。

选中网格，在建模里打开 **PolyGroup Edit**：

| 名字 | 是什么 |
| --- | --- |
| 顶点 | 那些点 |
| 边 | 那些线 |
| 面 | 网格的一个侧面 |

点一个面，再点 **挤出**，会拉出一个新面。想要窄墙时，不要直接挤整块大面，否则整面一起出去。先挤出薄薄一条，再用这条窄面继续挤，一面墙就出来了。其他几面重复同样的步骤。

还有两个常用工具，这节知道差别即可：

- **Push/Pull**：和挤出相近，但可以把面推进去、把厚度减下来。
- **倒角**：要先选中边。多边形很少时效果不好看。

## 练习

用建模工具做一个简单的盒子或半围合的墙，点接受，在 Generated 文件夹里找到它。不留的就删掉。

# 8. 材质

初学者内容包里就有现成材质，拖到物体上即可。网格材质方便开发时目测大小和位置，不好看，正式看效果时换掉。

## 贴图被拉大

同一张材质，放在小立方体上正常，铺到大地板上却被扯得很稀，多半是 **UV** 不匹配：这块模型的 UV 不是按这个材质铺的。

打开材质，找到 **纹理坐标（Texture Coordinate）**，把平铺数值调大。数字越大，贴图重复得越密。U 和 V 可以分开调。改完保存，等它编译。

课上地板先试了再乘 10、甚至 50；墙面的金属网格调到 8 就够看。最好不要为了一个物体去改母材质的平铺，以后用材质实例。这节先知道有这件事。

## 自发光

有的材质接了 **自发光颜色（Emissive Color）**，表面自己会亮，看起来像科幻墙。场景里还要另加灯光时，它会和光源抢效果。墙和地面先用不会发光的材质，比如金属、石材。木头不合适就换掉，不必硬留。

## 自己做一个

内容浏览器里新建 `Materials` 文件夹。右键或点加号 → **材质**。命名习惯是 `M_` 开头，例如 `M_Basic`，M 表示 Material。

打开后最右侧是材质的输出节点。没开 Substrate 时，这个输出节点和开了的不一样。基本接法相同，见下一节。

# 9. 材质节点和材质实例

Substrate 是虚幻做分层材质用的，感兴趣可以开着学。右边那些 Substrate 专用项先不管。左侧预览球什么都没接时是白的，节点接上才变。

## 常用插槽

在图表空白处按住数字键再点击，可以直接丢节点。小键盘 **3** 是颜色（三个值），小键盘 **1** 是一个浮点数。已有颜色码就直接填。

| 插槽 | 接什么 | 怎么理解 |
| --- | --- | --- |
| 基础颜色 | 颜色常量 | 表面颜色。不接上，预览不会变 |
| 金属度 | 0 到 1 | 0 非金属，1 全金属 |
| 高光 | 默认 0.5 | 主要看非金属。全金属时通常不起作用，玻璃上可以超过 1 |
| 粗糙度 | 默认 0.5 | **越小越亮**。0 像玻璃，1 像粉笔 |
| 法线 | 法线贴图 | 纯色用不上。贴图必须和颜色贴图是同一套，换错会出现怪纹路 |
| 自发光颜色 | 数值 | 0 不发光。5 已经很亮，很大的数会刺眼 |
| 不透明度 | 0 到 1 | 0 完全看不见，1 完全不透。0.2 比 0.7 更透 |

课上那颗球：金属度 1、粗糙度调到还会反光但不刺眼。高光留 0 就行。自发光保持 0。

法线贴图怎么画，这门课不讲。改错了用 `Ctrl + Z` 退回。玻璃的折射率也先跳过，没有固定配方，弄懂这几项之后自己试。遮罩、叠加这些混合方式以后再讲。

做好后保存，拖到关卡里的物体上即可。

## 材质实例

只改颜色、粗糙度或金属度时，不要每个变体都新建一份材质。右键父材质 → **创建材质实例**。实例是子级，省资源，运行时也更好改。

实例里一开始没什么可调的。回到父材质，在要暴露的节点上右键 → **转换为参数**，起个名字，比如 `Color`、`Metallic`。保存后，实例里就会出现这一项。

- 改某个实例：只有用了这份实例的物体会变。黄、绿、白就各做一个实例。
- 改父材质里没被实例单独盖住的值：所有实例一起变。比如在父级关掉金属度，这些颜色会一起变成非金属。
- 金属度填 0，不要填负数。

## 练习

给自己的场景做材质，用实例分出几种颜色，装饰一下。

# 10. 灯光

模板里默认的定向光就是太阳。通常一盏就够，不要再叠很多盏。放灯从顶栏的灯光图标进，或 **窗口 → 放置 Actor → 灯光**。

## 定向光

在细节里改这几项就够：

- **强度**：0 等于没光，1 很暗。课上用 3。
- **灯光颜色**：改气氛。先可以不动。
- **源角度、色温**：主光是太阳时保持默认。色温只是偏冷偏暖，这节不用管。

**投射阴影**可以按灯关掉。多盏灯都投影时，物体上会有多道影子。一小块地方不要放上百盏都在投影的灯，浪费计算。**影响世界**多数情况保持打开。

想要黄昏：按住 `Ctrl + L` 转太阳的方向。

## 三种局部光

| 灯 | 照哪里 | 先记这个 |
| --- | --- | --- |
| 点光源 | 四周一个球 | 圆圈是半径 |
| 聚光灯 | 一个锥体，游戏里最常用 | 有方向，用来打灯、打某个物体 |
| 矩形光 | 一块矩形 | 改宽高就是改光源形状 |

点光源先看半径。**源半径**是 0 时，**软源半径**没有作用；源半径设成 1 就够让软边生效。调的是衰减：从多远开始变暗。**源长度**会把灯泡拉成一根灯管，多数时候不用动。

聚光灯的 **衰减半径**是照多远。转 Y、Z 能改方向，转 X 几乎没差别。

- **内锥角**：最亮的那一圈，强度作用在这里。
- **外锥角**：从这里开始变暗。
- 内外一样大：边缘很硬。内小外大：中间亮、边上柔。内锥设成 0：整束都柔。
- 可以收得很小去打一个物体，但别小到像单独被打了一盏可疑的灯。

矩形光照向地面后，用源宽度、源高度定形状。**挡光板角度**调小，影子会变成很利落的矩形；挡光板长度决定这块影子有多硬、多方。

影响世界、投不投影，三种灯都一样，和定向光那套相同。

## 练习

在场景里加几处简单的光：台灯、火把、壁炉都行，也可以改颜色。先能放进去、挪得动。带交互的复杂布光以后再讲。

# 11. 蓝图

同一盏灯要放很多份时，不要在场景里一盏盏挂光源。选中物体，用按钮把它转成蓝图类。问子类时，静态网格体直接选即可。命名用 `BP_` 开头，集中放在内容浏览器的 `Blueprints` 文件夹。

蓝图编辑器里先认三块：视口里改物体，**事件图表**里写逻辑，**构造脚本**下一课再讲。

## Actor 是什么

关卡里摆出来的东西几乎都是 Actor：方块、玻璃、灯、草，也包括看不见但有用的物体。它不是指角色。

材质、颜色、贴花、粒子效果不是 Actor，只是挂在 Actor 上的外观或组件。角色是 Actor；做成投射物的火球也是；包在火球外面的火焰是粒子组件。

静态网格体只能改变换和一些引擎互动设置。细节面板里大部分先别动。转成蓝图之后，才能给它加行为：发光、移动、爆炸。能做的事有限制，但这是加功能的地方。

## 灯挂在网格体上

在蓝图视口里加一盏聚光灯，朝上，对准灯罩上的光源。它会出现在静态网格体组件下面，成为子级。缩放父级，子级跟着变。课上用一个立方体试过，确认之后删掉再编译。

改灯的半径、强度、颜色后要点 **编译**，回到关卡才能看到。课上半径 500，强度先试 1 万，再调到 2 万，和天花板那盏对齐；颜色试过红色，最后改回白色。

视口里物体小，把鼠标速度调低。找不到物体时，选中后按 `F`，关卡里也一样。掉到地板下面也能用这个找回来。

直接在关卡里挂灯也能亮。做成蓝图，是为了后面能加逻辑，一份改完，放进关卡的每一盏都带这套功能。

## 事件

事件是触发脚本的开关。新建蓝图里默认有三个。

**Event BeginPlay**：这个 Actor 在关卡里，并且开始播放时执行。不在关卡里就不会跑。中途生成这个蓝图时，也会在它被创建时执行。

用 **Print String** 写一句 `hello hello` 来确认有没有触发。编译后播放，屏幕上出现这句字，说明 BeginPlay 跑了。把灯从关卡拿走再播放，这句话就没了。

**Event Actor Begin Overlap** 是开始重叠。物体得先有碰撞。视口里可以看 **玩家碰撞** 和 **可见性碰撞**，两者不一样。地上的草不挡玩家，门和大多数物体会挡。碰撞怎么设，下一章再讲。门现在只会挡人，不会打开。可以做成走近自动开，也可以做成按键开。这节准备删掉用不到的 Tick 和 BeginPlay，图还没接上就断了。
