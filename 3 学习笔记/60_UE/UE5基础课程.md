# 4. 窗口、导航与快捷键

认四个面板，会摆窗口，会飞镜头，会用 W / E / R 改物体。

## 四个面板

| 面板 | 在哪 | 干什么 |
| --- | --- | --- |
| 放置 Actor | 左侧 | 把形状、灯光、自己的蓝图拖进场景 |
| 世界大纲 | 右侧 | 关卡里所有对象的列表 |
| 细节 | 选中后出现 | 改位置、旋转、缩放、网格、材质 |
| 内容浏览器 | 底部 | 项目里的资产：网格、材质、道具、粒子 |

大纲里可以建文件夹归类。选中文件夹或按住多选，就能一起隐藏、移动，不用一个个点。

细节里改数字，视口里的物体会跟着变。缩放旁边的锁打开后是等比缩放。想换模型、保留原来的位置和大小：在细节里换网格体。换材质同理。撤销是 `Ctrl + Z`。

内容浏览器里，初学者内容包适合拿来试手。道具文件夹里的网格直接拖进场景。不想它缩回去，点 **停靠到布局**。

## 窗口布局

面板可以拖出来变成独立窗口，也能拖到屏幕任意一边重新停靠，关掉也行。

- 找回某个窗口：顶部 **窗口** 菜单。
- 同一个窗口可以开多份。
- 布局乱了：**窗口 → 加载布局 → 默认编辑器布局**。
- `Ctrl + 空格`：把内容浏览器、细节、大纲叫回来。

放置 Actor 是 UE4 那套经典布局里的。UE5 默认不一定有它，常用形状在快速添加里也能放进场景。

## 吸附

移动时一格一格跳，是因为吸附开着。

- 数值大（比如 100）：跳得远，方便粗对齐。
- 设成 1：更顺。
- 关掉：自由移动。

常用 1 或 10，场景不容易摆歪。旋转、缩放也有各自的吸附。

## 视口和播放

视口左上角三条横线是视口选项。里面的 **屏幕百分比** 决定画多清楚：

- 调低（如 25）：变糊，用来预览低分辨率。
- **100**：日常用这个。
- 调高（如 200）：更清楚，更吃性能。

进入游戏：点播放，或 `Alt + P`。第三人称模板里用 WASD 走、空格跳。退出播放用 `Esc`。

地形、植被、建模这些模式以后再讲，先知道顶栏能切换。

## 镜头和变换

**飞镜头**：按住鼠标右键再按键。

| 键 | 作用 |
| --- | --- |
| W A S D | 前后左右 |
| Q / E | 下降 / 上升 |
| 滚轮 | 加快或减慢飞行速度 |

松手后，Q / E / R / W 变成变换工具，和飞行时不是同一套。

| 键 | 作用 |
| --- | --- |
| W | 移动。拖箭头沿轴走，拖中心圆可在空间里自由拖 |
| E | 旋转 |
| R | 缩放 |
| Q | 只选择，隐藏操纵杆，避免误碰物体 |

顶栏对应图标和这些键是一样的。

# 5. 操作物体

在上一节的移动、旋转、缩放之上，加上复制、跟着走，以及换模型、换材质。

## 复制和镜头跟随

先选中物体，再按住修饰键拖操纵器。

| 操作 | 结果 |
| --- | --- |
| `Alt` + 拖动 | 复制一个 |
| `Shift` + 点击 | 多选。多选后再 `Alt` + 拖动，会一起复制 |
| `Shift` + 拖动 | 不复制，摄像机会跟着物体走 |
| `Shift` + `Alt` + 拖动 | 复制，并且摄像机跟着新副本走 |

多选后旋转，会绕**最后选中**的那个转。操纵器停在谁身上，就是绕谁转。

## 换网格和换材质

想换模型、保留原来的位置和变换：在细节面板的静态网格体里换。

两种换法：

- 在细节里直接搜索、点选。
- 内容浏览器里先点中目标资产，再点细节面板里的**箭头**，当前物体就换成浏览器里选中的那个。

网格、材质，以及其他能从内容浏览器指定的资产，都可以用这个箭头。

找不到资产在哪：点网格或材质旁边的定位图标，会跳到内容浏览器里的文件夹。初学者内容包的道具一般在 `Content/StarterContent/Props`。

换材质还有两种：从列表里选，或直接把材质拖到物体上。刚换上时可能要等着色器编译。

## 数值框可以算式

缩放旁边的锁：没锁只沿一个轴变，锁上是等比。

数值不用先心算。在输入框里直接写运算，引擎会算出结果，细节面板以外的数值框大多也行。

- `1+0.5`：在当前值上加
- `*2`：变成两倍
- 除法同样可以写

细节面板里还有不少选项，这节先不用记。

## 练习

打开初学者内容包的 Props，拖几个静态网格进场景，搭一小块布景。用来练复制、多选旋转、换模型和换材质。
