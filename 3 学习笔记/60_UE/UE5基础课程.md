# 4. 窗口、导航与快捷键

认四个面板，会摆窗口，会飞镜头，会用 W / E / R 改物体。

## 四个面板

| 面板 | 在哪 | 干什么 |
| --- | --- | --- |
| 放置 Actor | 左侧 | 把形状、灯光、自己的蓝图拖进场景 |
| 世界大纲 | 右侧 | 关卡里所有对象的列表 |
| 细节 | 选中后出现 | 改位置、旋转、缩放、网格、材质 |
| 内容浏览器 | 底部 | 项目里的资产：网格、材质、道具、粒子 |

大纲里可以建文件夹归类。选中文件夹或按住多选，就能一起隐藏、移动，不用一个个点。

细节里改数字，视口里的物体会跟着变。缩放旁边的锁打开后是等比缩放。想换模型、保留原来的位置和大小：在细节里换网格体。换材质同理。撤销是 `Ctrl + Z`。

内容浏览器里，初学者内容包适合拿来试手。道具文件夹里的网格直接拖进场景。不想它缩回去，点 **停靠到布局**。

## 窗口布局

面板可以拖出来变成独立窗口，也能拖到屏幕任意一边重新停靠，关掉也行。

- 找回某个窗口：顶部 **窗口** 菜单。
- 同一个窗口可以开多份。
- 布局乱了：**窗口 → 加载布局 → 默认编辑器布局**。
- `Ctrl + 空格`：把内容浏览器、细节、大纲叫回来。

放置 Actor 是 UE4 那套经典布局里的。UE5 默认不一定有它，常用形状在快速添加里也能放进场景。

## 吸附

移动时一格一格跳，是因为吸附开着。

- 数值大（比如 100）：跳得远，方便粗对齐。
- 设成 1：更顺。
- 关掉：自由移动。

常用 1 或 10，场景不容易摆歪。旋转、缩放也有各自的吸附。

## 视口和播放

视口左上角三条横线是视口选项。里面的 **屏幕百分比** 决定画多清楚：

- 调低（如 25）：变糊，用来预览低分辨率。
- **100**：日常用这个。
- 调高（如 200）：更清楚，更吃性能。

进入游戏：点播放，或 `Alt + P`。第三人称模板里用 WASD 走、空格跳。退出播放用 `Esc`。

地形、植被、建模这些模式以后再讲，先知道顶栏能切换。

## 镜头和变换

**飞镜头**：按住鼠标右键再按键。

| 键 | 作用 |
| --- | --- |
| W A S D | 前后左右 |
| Q / E | 下降 / 上升 |
| 滚轮 | 加快或减慢飞行速度 |

松手后，Q / E / R / W 变成变换工具，和飞行时不是同一套。

| 键 | 作用 |
| --- | --- |
| W | 移动。拖箭头沿轴走，拖中心圆可在空间里自由拖 |
| E | 旋转 |
| R | 缩放 |
| Q | 只选择，隐藏操纵杆，避免误碰物体 |

顶栏对应图标和这些键是一样的。

# 5. 操作物体

在上一节的移动、旋转、缩放之上，加上复制、跟着走，以及换模型、换材质。

## 复制和镜头跟随

先选中物体，再按住修饰键拖操纵器。

| 操作 | 结果 |
| --- | --- |
| `Alt` + 拖动 | 复制一个 |
| `Shift` + 点击 | 多选。多选后再 `Alt` + 拖动，会一起复制 |
| `Shift` + 拖动 | 不复制，摄像机会跟着物体走 |
| `Shift` + `Alt` + 拖动 | 复制，并且摄像机跟着新副本走 |

多选后旋转，会绕**最后选中**的那个转。操纵器停在谁身上，就是绕谁转。

## 换网格和换材质

想换模型、保留原来的位置和变换：在细节面板的静态网格体里换。

两种换法：

- 在细节里直接搜索、点选。
- 内容浏览器里先点中目标资产，再点细节面板里的**箭头**，当前物体就换成浏览器里选中的那个。

网格、材质，以及其他能从内容浏览器指定的资产，都可以用这个箭头。

找不到资产在哪：点网格或材质旁边的定位图标，会跳到内容浏览器里的文件夹。初学者内容包的道具一般在 `Content/StarterContent/Props`。

换材质还有两种：从列表里选，或直接把材质拖到物体上。刚换上时可能要等着色器编译。

## 数值框可以算式

缩放旁边的锁：没锁只沿一个轴变，锁上是等比。

数值不用先心算。在输入框里直接写运算，引擎会算出结果，细节面板以外的数值框大多也行。

- `1+0.5`：在当前值上加
- `*2`：变成两倍
- 除法同样可以写

细节面板里还有不少选项，这节先不用记。

## 练习

打开初学者内容包的 Props，拖几个静态网格进场景，搭一小块布景。用来练复制、多选旋转、换模型和换材质。

# 6. 整理场景

一组要一起搬的物体用编组。大纲里只是想归类、好找，用文件夹。两件事不要混。

## 编组

`Shift` 点选要放在一起的物体，再 `Ctrl + G`。之后点一个就是整组，移动也是整组。

| 操作 | 结果 |
| --- | --- |
| `Ctrl + G` | 编组 |
| `Shift + G` | 取消编组 |

右键菜单里的 **组**，以及大纲里的组 Actor，和这两个快捷键是一样的。

只想挪组里的某一个、又不想拆开再重编：关掉 **允许组选择**。它们还是一组，但可以单独选、单独移。改完再打开，就恢复成整组选中。组里物体很多时用这个，比反复拆组合算。

## 文件夹

大纲右上角带加号的文件夹图标用来新建文件夹。创建时如果已经选中物体，它们会自动进这个文件夹，也可以之后再拖进去。文件夹里还能再建子文件夹。

文件夹只负责在大纲里归类。同一文件夹里的物体，不会因此变成一组。编组 Actor 可以再拖进某个子文件夹，旁边没编进去的物体仍然是单独的。

## 练习

把上一节搭的小布景整理一遍：该编组的编组，其余放进文件夹，让大纲能直接点到想要的东西。

# 7. 建模工具

关卡里的占位块可以直接在虚幻里做，不必先去别的软件。这节只做白模，颜色和光照以后再改。

## 打开插件

虚幻 5.4 里更多建模工具要手动开：**编辑 → 插件**，搜索 `modeling`。两个都启用：

- Modeling Tools Editor Mode
- Static Mesh Editor Modeling Mode

都还是 Beta。启用后按提示重启。然后从顶栏进入 **建模** 模式。插件里内置的、商城里的、自己装的都在这一页，用搜索找，不用逐个翻。

## 拉一个盒子

选盒子。矩形只是一个平面，做墙体用处不大。

- 宽高默认滑条是 1 到 1000，可以手打更大的数。课上先设 500，再挪位置、拉大，厚度改成 20。
- 细分能让模型更细，做原型可以不提。
- 输出类型选 **静态网格体**。材质可以现在指定，也可以以后再换。
- 必须点 **接受**，网格才会真正生成。取消会丢掉还没接受的修改。

生成的网格在内容浏览器的 Generated 文件夹里。选中物体，用旁边的定位图标就能跳过去。不用的记着删，免得堆一堆临时模型。

## 在同一块网格上挤出

这样做出来的是**一整块网格**，不是几片分开的平面。要在侧面加墙，就改这一块，不要再各拉一个盒子。

选中网格，在建模里打开 **PolyGroup Edit**：

| 名字 | 是什么 |
| --- | --- |
| 顶点 | 那些点 |
| 边 | 那些线 |
| 面 | 网格的一个侧面 |

点一个面，再点 **挤出**，会拉出一个新面。想要窄墙时，不要直接挤整块大面，否则整面一起出去。先挤出薄薄一条，再用这条窄面继续挤，一面墙就出来了。其他几面重复同样的步骤。

还有两个常用工具，这节知道差别即可：

- **Push/Pull**：和挤出相近，但可以把面推进去、把厚度减下来。
- **倒角**：要先选中边。多边形很少时效果不好看。

## 练习

用建模工具做一个简单的盒子或半围合的墙，点接受，在 Generated 文件夹里找到它。不留的就删掉。
