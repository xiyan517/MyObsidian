# UE5 入门（编辑器界面与基础操作）

> [!summary]
> 第一课目标不是做完整游戏，而是把 **UE5 编辑器转起来**：新建项目 → 认四大区域 → 会飞镜头 → 会切显示模式 / 书签 / 吸附 → 知道内容浏览器怎么管资产。布局思路接近 [[01_基础知识|Blender]]、C4D、Photoshop：中间大视口，四周是菜单、大纲和属性。

## 1. 界面总览

UE 的默认布局和常见 DCC / 平面软件很像：

| 区域 | 干什么 | 可对照 |
| --- | --- | --- |
| 中间大视口 | 看场景、飞镜头、摆物体 | Blender 3D 视口、PS 画布 |
| 左上菜单 / 工具栏 | 保存、模式、运行、过场 | 各软件顶栏 |
| 右侧大纲 + 细节 | 选对象、改属性 | PS 图层面板 + 属性 |
| 底部内容浏览器 | 管资产文件 | 资源管理器 |

先认面板，再记快捷键。点不开的菜单先知道「它在哪一类」，比死记每一个按钮重要。

---

## 2. 启动与新建项目

1. 打开 Epic Games 启动器，启动 **UE5**。
2. 进入 **项目浏览器**：最近项目、新建、引擎自带模板都在这里。
3. 选一类游戏模板（第一人称等），需要的话勾选 **起始内容（Starter Content）**，再填项目名、路径。
4. 创建后引擎会导入模板关卡、灯光、基础网格等，方便直接点、直接改。

> [!tip]
> 课上建议：这节课听完，回到项目浏览器再随便打开几个 **UE5 内置模板**，靠点击熟悉界面，比只看演示记得住。

项目设置里可以改显示名、图标等。这些不影响你学操作，知道「能改」即可。

---

## 3. 主界面四大区域

打开关卡后，默认能看到：

### 3.1 视口（Viewport）

中间那块实时画面。镜头远近、角度、线框/光照，都在这里看。和 C4D、Blender 一样，**先会转视角，再摆物体**。

### 3.2 世界大纲（Outliner）

场景里当前关卡的对象列表：网格、灯光、摄像机、体积等。点一项，视口里对应选中。

### 3.3 细节面板（Details）

当前选中对象的属性：位置 XYZ、旋转、缩放、渲染相关、灯光强度等。课上特别强调一个高频技巧，见 §5。

### 3.4 内容浏览器（Content Browser）

也叫内容管理器 / 资源管理器。

- 视口里看到的网格、材质、贴图，**原始文件都放在这里**。
- 后面创建的 **蓝图** 资产，一般也落在这里。
- UE4 默认常常是展开的；UE5 做了 UI 收纳，**要点一下才会展开/聚焦**，别以为没了。

> [!note]
> 大纲管「关卡里已经放出来的实例」；内容浏览器管「磁盘上的资产」。同一个静态网格可以拖进关卡很多次。

## 4. Nanite 与 LOD（点到为止）

UE5 有一项相对 UE4 更醒目的技术：**Nanite**。

- 引擎可以按模型离镜头的远近，决定哪些像素真正参与渲染、哪些不必画满。
- 目的是在高模场景里抬 **性能和流畅度**，减轻传统 **LOD（Levels of Detail）** 那套手工减面的负担。
- 课上对比：Nanite 的观感通常优于老式 LOD 切换；**这门课前期可以先不用**，知道它是什么即可。
- 模板/默认导入的很多模型 **没有预先做好 Nanite**。需要时在静态网格编辑或对应工具里 **启用 Nanite**。

灯光、环境、后期（质量、氛围）也会画进视口。有的效果要 **运行游戏** 才和编辑器里完全一致，见 §6.4。

## 5. 细节面板：把属性拷到另一个对象

课上认为比较实用的小功能：

1. 选中物体 A，在细节里找到要复用的那一组属性（例如变换：X / Y / Z）。
2. **右键 → 复制**。
3. 再选物体 B，**右键 → 粘贴**。

不限于位置。渲染、灯光等很多属性都可以这样拷。场景里调好一处，就能快速铺到同类对象上。

## 6. 工具栏：模式、放置、蓝图、过场、运行

工具栏左侧会随「你在干什么」切换整套工具。

### 6.1 编辑模式

| 模式 | 典型用途 |
| --- | --- |
| **选择**（默认） | 选物体、摆位置，日常就用这个 |
| **地形** | 雕刻、绘制地表 |
| 植被 / 网格绘制 / 建模等 | 对应各自工具条，课上让自己点开看一遍 |

不同模式 = 不同工具集。以后「找不到按钮」，先看是不是切错模式。

### 6.2 快速添加 / 放置 Actor

把常用要「扔进关卡」的东西做成集合：基础几何、灯光、体积、视觉特效等。顶栏菜单里也能找到同样的类，这里只是入口更近。

### 6.3 关卡蓝图与过场序列

| 入口 | 作用 | 本课深度 |
| --- | --- | --- |
| 关卡蓝图（世界/场景蓝图） | 当前关卡逻辑 | 讲到蓝图再展开 |
| 过场序列（Sequencer / Cinematics） | 镜头一切到镜头二、转场、过场动画 | 讲到动画/过场再展开 |

过场序列资产，习惯放在内容浏览器的 `Movies` 文件夹，见 §10。

### 6.4 运行、暂停、视口与独立进程

编辑器视口里看到的，主要是 **编辑预览**。游戏做到一定程度后，要点 **运行（Play）** 看真实规则下的状态。

- 有些效果 **只有运行模式** 才正确。
- 键盘 **`Esc`** 退出预览，回到编辑。
- 运行目标默认是 **选中的视口**（中间这块）。
- 可改成 **独立进程 / 独立窗口**：单独弹窗播游戏，左右编辑器 UI 被挡掉，更接近玩家看到的画面。

> [!warning]
> 「视口里关掉某效果」≠「打包/运行后也没有」。显示开关只作用于当前预览视口，见 §8.6。

## 7. 视口镜头控制

和很多第一人称游戏同一套方向，但 **平移飞行时要按住鼠标中键**（课上教法）。

| 操作 | 做法 |
| --- | --- |
| 推近 / 拉远 | 滚轮 |
| 前 / 后 / 左 / 右 | 按住 **中键** + `W` `S` `A` `D` |
| 镜头降低 / 抬高 | 按住中键 + `Q` / `E` |
| 横向挪镜头 | 按住 **左键** 拖 |
| 360° 环看 | 按住 **右键** 拖 |
| 把选中物体放到视野中心 | 选中后按 `F` |

大模型按 `F` 会把镜头拉得很远；换小物体再按 `F`，镜头会收回来。用来在杂乱场景里「找回」选中物。

> [!note]
> 变换快捷键里的 `E` 是旋转（§9.1）；飞镜头时按住中键的 `E` 是升高。看你当时在不在「飞行」。官方更常见的飞镜头是 **按住右键 + WASD**，和本课「中键 + WASD」可以并存，按自己顺手的来。

## 8. 视口左上角菜单

三条横线进去是 **视口选项**。课上高频这几项。

### 8.1 显示 FPS

当前视口每秒帧数。游戏开发里经验线是 **至少 60 FPS**；长期低于 60，会觉得场景发卡。后期做优化时要一直开着看。

### 8.2 书签（管理镜头机位）

用来记住多个观察角度，不必来回飞。

1. 摆好角度，`Ctrl + 0` / `Ctrl + 1` / `Ctrl + 2` … 写入书签。
2. 之后直接按 `0` `1` `2` … **跳到**对应机位。

适合在同一关卡里快速对比几个构图、检查灯光。

### 8.3 从此处创建相机

当前视口角度很好、想留作正式机位时：视口菜单 → **从此处创建相机**。

两种相机里，课上一般选第二个：**Cine Camera Actor（电影摄像机）**。比普通 Camera Actor 属性更多（焦距、光圈、胶片门等），后期按大屏比例预览也更合适。

创建后：选中该相机 → 右键 → **控制摄像机（Pilot）**。视口会改成这台相机的取景，而不是默认编辑器镜头。

- 默认编辑器镜头往往铺满整个屏幕。
- 项目常按目标大屏 / 电影画幅设比例；用电影摄像机预览，才接近最终观感。

### 8.4 高分辨率截图

用来跟同事沟通效果，比微信/系统截图更干净，分辨率还能拉高。

1. 打开高分辨率截图。
2. **截图分辨率乘数**（字幕里「截图尺寸乘数」是误译）：视口若是 `1920×1080`，填 `2` 就是约两倍像素。
3. 截完右下角通知，点进去打开保存目录；空格可预览。

适合汇报进度、对比调光前后。

### 8.5 透视与显示模式（Lit / 线框 / 仅光照）

透视切换（顶、前、侧等）和 C4D、Blender 的正交/透视切换是一类事：换角度检查模型有没有穿插、摆正。

**光照/缓冲显示模式**日常少用，主战场是调试和优化：

| 模式 | 何时用 |
| --- | --- |
| 默认光照（Lit） | 看最终观感 |
| **线框（Wireframe）** | 场景卡、或要看布线。关掉材质和光照，视口会顺很多；只挪模型位置时很合适。表面布线异常也能一眼看出来 |
| **仅光照** | 屏蔽材质颜色，只看光强、阴影是否合适 |

卡的时候先切线框，确认是「场景太重」还是「某个模型本身有问题」。

### 8.6 显示（Show Flags）

控制 **当前视口** 里哪些效果画出来：大气、雾、后处理、体积等。

课上例子：把某一类天空/大气相关显示勾掉，视口里立刻没了；一点 **运行**，游戏里天空还在。

结论：

- 这些开关 **不影响运行时/打包结果**。
- 用途：排查「到底是哪一层效果出问题」——先关掉你觉得没问题的，缩小范围。
- 做性能对比时，也可以逐项关，看谁在吃帧。

和 §8.5 的显示模式是同一类「编辑器诊断工具」。

## 9. 视口右上角：变换、吸附、速度、四视图

### 9.1 平移 / 旋转 / 缩放

| 操作 | 快捷键 | 说明 |
| --- | --- | --- |
| 平移 | `W` | 沿轴拖箭头 |
| 旋转 | `E` | 沿轴转 |
| 缩放 | `R` | 可单轴；鼠标放到中心、XYZ 都亮 = 等比缩放 |

按住 `Shift` 可沿轴更克制地平移（课上演示）。激活的轴会高亮，再拖。

### 9.2 世界空间 ⇄ 本地空间

小图标在世界坐标和物体本地坐标之间切。从 UE4 按世界坐标对过的场景导进来时，这边也切到 **世界**，两边数字才一一对应。

### 9.3 网格吸附（移动）

拖物体时要不要吸到网格上。按钮变蓝 = 开。

- 默认步长常见是 `10`；课上改成 `100` 后，每拖一下就是 100 单位。
- 关掉之后移动很顺滑。
- 适合把大量物体按 `100` / `500` 这种固定间距铺开。

### 9.4 旋转吸附

控制旋转步进。设 `10` 就每次约 10°；改 `5` 就是 5°。需要规整角度就开，要微调就关（可转到小数点后两位）。

### 9.5 缩放吸附

是否按缩放网格对齐、对齐精度。默认常见 `0.25`：边缘离网格约 0.25 单位就会吸上去。值越大吸得越狠。一般默认即可；场景尺度极大再加大。

### 9.6 摄像机速度

按住中键用 WASD 飞的时候，快慢由这里决定。

- 调成 `2`：明显变慢，适合精细看局部。
- 调成 `8`：场景很大时一下飞过去。
- 下面还有一个 **乘数**：上面 `2`、下面再 `2`，等效速度 `4`。

### 9.7 四视图

打开后同时看到：透视图（全光照实时）+ 顶视图 + 前/后一类正交线框。

摆位置时最有用：一个角度看着对，换个正交一看可能已经陷进地面。点某个子视口的 **最大化 / 恢复**，可以把它当主视口用。

## 10. 内容浏览器：文件夹约定与收藏夹

内容浏览器是场景资产的总账本。文件夹命名和摆放 **有约定**，乱放后期打包会找不到。

| 位置 | 典型内容 |
| --- | --- |
| `Movies` | 过场序列（Sequencer）。部分 **UMG / 过场相关特殊贴图** 也要放这里，否则打包时引擎识别不到。讲 UMG 动画时会再强调 |
| 其他按类型分的目录 | 网格、材质、蓝图、贴图等，团队会再定规范 |

**收藏夹**：在文件夹上右键 → 添加到收藏夹。项目目录会套很多层，日常真正常点的往往就七八个。收藏后出现在靠前位置，不用每次层层点。

## 11. 课后小结

1. **布局**：中间视口 + 顶栏菜单 + 右侧大纲/细节 + 底栏内容浏览器，接近 Blender / PS。
2. **视口左上**：场景怎么显示（FPS、书签、相机、截图、线框、Show Flags）。
3. **视口右上**：物体怎么动（W/E/R、世界/本地、三种吸附、飞镜头速度、四视图）。
4. **飞镜头**：中键 + `WASD`，`Q`/`E` 降升；`F` 聚焦。
5. **运行**：编辑器预览 ≠ 游戏运行；`Esc` 退出；可用独立窗口看沉浸效果。
6. **练习**：用项目浏览器打开几个内置模板，把本节快捷键在真实关卡里走一遍。
