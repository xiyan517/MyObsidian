# 杂项

> [!summary]
> LangChain / LangGraph / Ollama 项目的 **ML 环境搭建**（Windows / Linux / Mac，可选 GPU）。用 Conda 建 `ml`（Python 3.12）→ 装依赖与 PyTorch → 校验 CUDA → 挂 Jupyter kernel。

前置：安装 [Anaconda / Miniconda](https://www.anaconda.com/docs/getting-started/anaconda/install#basic-install-instructions)。

## 1. 建环境

### 1.1 检查 Conda

```bash
conda --version
conda env list
```

### 1.2 创建环境

```bash
conda create -n ml python=3.12 -y
```

### 1.3 关闭 base 自动激活（建议）

```bash
conda config --set auto_activate_base false
```

### 1.4 让终端自动进 `ml`（可选）

**Windows PowerShell**

```powershell
# 创建/编辑 profile；若不存在：
# New-Item -Path $PROFILE -Type File -Force
notepad $PROFILE

# 写入一行：
conda activate ml

# 保存后重载
. $PROFILE
```

**Linux / Mac**

```bash
# Bash → ~/.bashrc；Zsh → ~/.zshrc
nano ~/.bashrc   # 或 ~/.zshrc

# 写入一行：
conda activate ml

source ~/.bashrc  # 或 source ~/.zshrc
```

### 1.5 手动激活并进入项目

```bash
conda activate ml
cd path/to/your/project
```

## 2. 装依赖

### 2.1 项目依赖

```bash
pip install -r requirements.txt
```

### 2.2 PyTorch（按本机 CUDA 选索引）

到 [PyTorch 官网](https://pytorch.org/get-started/locally/) 选版本与 CUDA，再安装。示例（CUDA 12.8 wheel）：

```bash
pip install torch torchvision --index-url https://download.pytorch.org/whl/cu128
```

> [!note]
> CUDA 版本要以本机驱动与官网当前推荐为准；`cu128` 只是课程/原文示例，不一定适合你的机器。

---

## 3. 校验

### 3.1 GPU

```python
import torch
torch.cuda.is_available()      # 应为 True
torch.cuda.get_device_name(0)   # 显卡名
exit()
```

### 3.2 Jupyter Kernel（VS Code）

1. 打开 notebook
2. 按提示安装 `ipykernel`（如需要）
3. 选中 kernel：`ml (Python 3.12.x)`
4. 再测：`import torch; torch.cuda.is_available()`

## 4. 排错

**Conda 命令找不到**

- **Windows：** 把 Anaconda/Miniconda 加入 PATH（重启终端），例如：
  - `C:\Users\YourName\anaconda3`
  - `...\anaconda3\Scripts`
  - `...\anaconda3\Library\bin`
  - 或直接用 Anaconda Prompt
- **Linux / Mac：**

```bash
source ~/anaconda3/bin/activate   # 或 ~/miniconda3/...
conda init bash                   # 或 conda init zsh
```

然后重启终端。

**GPU 检测不到**

- 查驱动：`nvidia-smi`
- 按正确 CUDA 版本重装 PyTorch

**PowerShell 执行策略报错**

```powershell
Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser
```

**Kernel 列表里没有 `ml`**

```bash
pip install ipykernel
python -m ipykernel install --user --name ml
```

