# 文生图参数与快速出图

> [!summary]
> **AIGC · 第 2 部分**。把 WebUI 文生图走通一遍：顶栏选模型 → 按四段写正向 / 反向提示词 → 调步数、采样器、尺寸、批次、CFG、种子 → **先出小图试错，满意后固定种子，再开高清修复出大图**。提示词必须用英文，词与词之间用英文逗号隔开。

采样器这一课标出了四种用法，放在 §6。出图顺序仍然是：小图试错，满意后固定种子，再高清修复。

## 1. 这一课看哪一页

导航栏里多数是后装插件，后面的课才会用到。本节只留在 **文生图**。

生成按钮下方有一排小按钮。点中间那个，会展开模型卡片（大模型、LoRA、文本反转）。正向 / 反向提示词框右上角的 `Ctrl+Enter` 或 `Alt+Enter` 可以直接开始生成。

---

## 2. 顶栏：风格从模型来

最上面从左到右是三件套。大模型决定画面风格，VAE 和 CLIP 终止层数是配套开关。

| 控件 | 作用 | 本节用法 |
| --- | --- | --- |
| Stable Diffusion 模型 | 决定写实、二次元，还是别的风格 | 在下拉里选已下载的模型 |
| 旁边的刷新 | 新放进文件夹的模型有时不会立刻出现 | 点一次刷新 |
| 外挂 VAE | 和大模型配套，用来补细节、校颜色 | 有配套 VAE 就选上 |
| CLIP 终止层数 | 提示词先被 CLIP 编成符号，再拿去出图；这里选的是用编码器的哪一层 | 先保持 **2** |

> [!note]
> CLIP 终止层数不是「转化用几层」。CLIP 文本编码器有多层，WebUI 里的数字表示从最后一层往前用第几层：`1` 用最后一层，`2` 用倒数第二层。很多二次元模型按 `2` 训练，所以界面默认 `2` 就能用；写实模型有时要改回 `1`。这节先不动。

有的主页上看不到 VAE 和 CLIP 终止层数。到 **设置 → 用户界面**，在快速设置那一栏填入下面这一串，保存后点 **重启 UI**：

```text
sd_model_checkpoint, sd_vae, CLIP_stop_at_last_layers
```

重启时如果短暂打不开页面，等它自己刷新即可，回到文生图就能看到这两项。

## 3. 正向提示词和反向提示词

两个框都用英文写。

| | 正向提示词 | 反向提示词 |
| --- | --- | --- |
| 写什么 | 希望画面里出现的东西 | 不希望画面里出现的东西 |
| 例子 | `red hair` | `black hair, white hair, purple hair` |

反向不是把正向整句否定一遍。它用来把容易跑偏的元素按住：正向要红发时，反向里多写几种别的发色，出图就更接近预期。

每个正向质量词都配一条反向，只是一种写法示范，不是必须一一对应。

---

## 4. 提示词按四段来写

这个结构不是官方格式，是课程里自己用的书写习惯。好处是以后加词时知道该插在哪一段。

| 段 | 写什么 | 例子 |
| --- | --- | --- |
| 1 全局 | 画质、风格这类整张图都生效的词 | `best quality, masterpiece` |
| 2 主体 | 人、物、动物，以及和主体绑在一起的特征 | `a cute girl wearing a white sweater, smile, long hair, 1girl` |
| 3 场景 | 主体在哪里 | `nature, tree, grass` |
| 4 效果 | 光感、镜头气质 | `lens flare, cinematic` |

主体尽量写成短语，不要拆成互不相干的单词。`a cute girl wearing a white sweater` 比单独丢 `girl, cute, sweater` 信息更密，模型更好画。短语内部用空格，短语和短语之间用英文逗号。

### 4.1 全局词和对应的反向词

课里用拆词根的方式记这些词，词源多半不可靠。下面只留能直接写进提示词的英文。

| 正向 | 含义 | 反向里对应写 |
| --- | --- | --- |
| `best quality` | 最佳质量 | `bad quality, low quality, normal quality` |
| `masterpiece` | 杰作 | 不想要差作品。口播没给英文，常用 `worst quality` |
| `high resolution` | 高分辨率 | `low resolution` |
| `intricate detail` | 复杂、丰富的细节 | `simple detail` |
| `photograph` | 摄影、照片。要写实时才加 | `painting`（不要画出来的感觉） |

`photograph` 只在想要照片感时加。二次元模型不必硬套这组。

### 4.2 课上那一轮用过的提示词

正向：

```text
best quality, masterpiece, high resolution, intricate detail, photograph,
a cute girl wearing a white sweater, smile, long hair, 1girl, red hair,
nature, tree, grass,
lens flare, cinematic
```

反向：

```text
bad quality, low quality, normal quality, worst quality,
low resolution, simple detail, painting,
black hair, white hair, purple hair
```

`lens flare` 是镜头光晕，画面会更有光感。`cinematic` 是电影感。发色那一行就是上一节说的约束：正向红发，反向排除黑、白、紫。

## 5. 第二个选模型的地方

生成按钮下方中间那个按钮打开模型卡片。上面一排是类型，下面一排是当前类型里的分类。点封面再往上翻，能看到软件在读这个模型。

![[02-model-folders.jpg]]

上面红框是 `models/Stable-diffusion` 里的子文件夹，下面红框是「模型(ckpt)」页上的分类按钮，两边是同一份名单。

| 文件夹 | 卡片上的分类 |
| --- | --- |
| `Anime` | `Anime/` |
| `ani real` | `ani-real/` |
| `effect` | `effect/` |
| `Realistic` | `Realistic/` |
| `space` | `space/` |

文件夹名里的空格，到界面上会变成连字符，所以 `ani real` 显示成 `ani-real/`。

类型页签这一课先认名字：

| 页签 | 这一课要知道的 |
| --- | --- |
| 模型 (ckpt) | 大模型，决定整体风格，和顶栏是同一个东西 |
| Lora | 在大模型上叠一小段风格或角色 |
| LyCORIS | 和 LoRA 同类的另一种插件模型 |
| 嵌入式 (T.I. Embedding) | 文本反转，用一个词触发一套预训练概念 |
| 超网络 (Hypernetworks) | 另一类附加网络 |
| `2.5D` | 课上新建文件夹之后多出来的入口，在页签最右侧 |

自定义分类：绘世启动器 → **模型管理** → **打开文件夹**，在 `Stable-diffusion` 里新建文件夹（课上的例子是 `2.5D`），把模型放进去。回到卡片点 **刷新**，新名字就会出现。文件夹名就是分类名。

## 6. 生成参数

截图里是界面空闲时的默认值（步数 20、批次 1）。课上真正出图时改过，以下面这张表为准。

| 参数 | 在做什么 | 怎么设 |
| --- | --- | --- |
| 迭代步数 Steps | 从一团噪点还原成图要走多少步 | **30–50**。课上先用 32，细化时改 40。太低，噪点还没还原干净，画面会怪。用 Euler a 时，超过 30–40 步基本没有增益 |
| 采样方法 Sampler | 去掉噪点的不同算法 | 先用下面标出的四种。界面上其余采样器这节先不逐个试 |
| 宽度 / 高度 | 出图尺寸 | 试稿 **512×512**。想要照片构图，把高度加大，变成竖长方形 |
| 总批次数 | 点一次生成，连续跑几批 | 想多要几张候选时加大。课上设 **4**，一次出 4 张 |
| 每批数量 | 每一批里同时算几张 | 显存紧或显卡一般，保持 **1** |
| 提示词引导系数 CFG Scale | 画面贴提示词有多紧 | **5–15**，先留默认 **7**。过高过低都容易怪 |
| 随机数种子 Seed | 同一套提示词和参数下，决定构图、光影、环境 | 默认 **-1**，每次随机。先不用手填数字 |

### 6.1 课上标出的四种采样器

界面上的采样器远不止这四个。图里的旁注是这一课实际要记住的。滑块停在 **32**，和试稿步数一致。

![[02-samplers.png]]

| 采样器 | 旁注 |
| --- | --- |
| Euler a | 更有创造力。步数不同，出来的图也不同。超过 30–40 步基本没有增益 |
| Euler | 最常见的基础算法，最简单，也最快 |
| DPM++ 2M Karras | 快，画质也不错 |
| DPM++ SDE Karras | 稍慢，画面更精致 |

想先跑通就用 **Euler** 或 **DPM++ 2M Karras**。同一套提示词想要更细的成图，换成 **DPM++ SDE Karras**。想靠步数看出明显不同的图，用 **Euler a**，步数停在 40 以内。

批次和每批数量要分开记：每批数量是同时塞进显存的张数，总批次数是排队跑几轮。显存不够时，把每批数量留在 1，用总批次数去要更多张图。

种子旁边两个按钮：骰子把种子设回 `-1`（重新随机）；绿色回收把**上一张图**的种子填回来。满意某一张之后再用回收，不要在试稿阶段锁死。

三个开关这一课用到两个：

| 开关 | 何时开 |
| --- | --- |
| 面部修复 | 画面里有人脸、想让五官更自然时 |
| 高分辨率修复 | 小图已经满意、准备出大图时。见 §8 |
| 平铺图 | 这节不用 |

## 7. 第一轮出图，然后细化

第一次生成（批次 4）用来核对提示词有没有被画出来：女孩、微笑、白毛衣、红发、自然场景都在，说明反向提示词把发色按住了。

觉得能看、但还不够好，按这个顺序改，再生成一次：

1. 正向、反向都写细一点，补上人物动态和场景。
2. 步数改到 **40**，多给一些细节。
3. 勾上 **面部修复**。
4. 加大高度，让比例更接近一张照片。

这一轮画面细节、人物神态会明显好于第一轮。如果还想要更大的尺寸和更密的细节，不要直接把宽高拉到很大，改走高清修复。

## 8. 高清修复：小图定稿，再放大

勾选 **高分辨率修复**。它让最终图更大，细节更多。

放大可以理解成：把图切成许多小块，再根据每一块已有的内容，去补块与块之间多出来的像素。补完之后尺寸上去了，细节也跟着多。

![[02-upscalers.png]]

红框是放大算法下拉，课上说就在这一组里选。名单还能往下滚，滚出去的那些更容易把画面修怪。按名字对风格：

| 放大算法 | 什么时候用 |
| --- | --- |
| `R-ESRGAN 4x+ Anime6B` | 二次元 |
| `R-ESRGAN AnimeVideo` | 动画、线条 |
| `R-ESRGAN 4x+` | 通用，写实也用这个 |
| `R-ESRGAN General 4xV3` | 通用的另一版 |
| `4x-UltraSharp` | 想要边缘更锐 |
| `R-ESRGAN 2x+` | 只做 2 倍放大时 |
| `ESRGAN_4x`、`BSRGAN`、`LDSR`、`ScuNET`、`ScuNET PSNR` | 同在红框里，上面几个对不上风格时再试 |

下拉下面还有一项 **潜变量**。那是在潜空间里放大，和上表这些超分模型不是同一路。这节用红框里的超分算法。

| 项 | 怎么设 |
| --- | --- |
| 放大算法 | 二次元用 `R-ESRGAN 4x+ Anime6B`，写实用 `R-ESRGAN 4x+` 或 `4x-UltraSharp` |
| 高清采样次数 | 一般 **15**。这个数稍微影响速度和质量。图中框里是 `0`，`0` 表示沿用上面的迭代步数；课上建议改成 15 |
| 重绘幅度 | **0.3–0.6**。拉太高会跑成另一张奇怪的图。图中滑块停在 `0.7`，已经高出这个范围，不要照着 0.7 设 |
| 放大倍数 | 最终尺寸的倍率。课上用 **2** |

重绘幅度是这里最容易设坏的一项。它决定放大时允许改掉多少原图。要「同一张图，只是更清晰」，就留在 0.3 到 0.6。

### 固定种子再放大

种子旁的绿色回收，会填入上一张图的种子。提示词和参数大体不变时，新图会和那张小图很接近。

所以出图顺序是：

1. 用小尺寸试。小图快，也不容易爆显存。
2. 挑到喜欢的一张，点绿色回收，把种子固定下来。
3. 打开高清修复，放大倍数设好（例如 2），再生成。

得到的大图和小图是同一张的延续，只是更清晰、细节更多。这是这节的试错方法：便宜的计算花在挑选上，贵的计算只花在已经看中的那一张上。

## 9. 本节就这些

1. 风格看大模型；VAE 补细节和颜色；CLIP 终止层数先留 2。
2. 提示词用英文、逗号分隔，按全局 → 主体 → 场景 → 效果来写。
3. 反向提示词用来排除不想要的元素，例如用别的发色把目标发色夹出来。
4. 试稿：步数 30–50（Euler a 不超过 40），采样器先用 Euler 或 DPM++ 2M Karras，512 尺寸，每批数量 1，需要候选就加大总批次数，CFG 留在 7 附近。
5. 看中一张之后固定种子，再开高清修复：二次元用 `R-ESRGAN 4x+ Anime6B`，写实用 `R-ESRGAN 4x+` 或 `4x-UltraSharp`；高清采样 15，重绘幅度 0.3–0.6，倍数 2。

## 速查

### 一组能直接开画的数值

| 项 | 试稿 | 看中之后 |
| --- | --- | --- |
| Steps | 32（或 30–50 之间；Euler a 不超过 40） | 可提到 40 |
| 采样器 | Euler，或 DPM++ 2M Karras | 要更精致改 DPM++ SDE Karras |
| 尺寸 | 512×512 | 宽度不动，高度可加大 |
| 每批数量 | 1 | 1 |
| 总批次数 | 4（想一次多看几张） | 1 即可 |
| CFG | 7 | 7 |
| Seed | -1 | 绿色回收，锁定上一张 |
| 面部修复 | 有人脸再开 | 开 |
| 高清修复 | 关 | 开。二次元 `R-ESRGAN 4x+ Anime6B`，写实 `R-ESRGAN 4x+` 或 `4x-UltraSharp`。采样 15，重绘 0.3–0.6，倍数 2 |

### 字幕里容易听错的词

口播加自动识别把术语写飞过，笔记里已按界面改成下面右列。

| 字幕里常见写法 | 实际指什么 |
| --- | --- |
| based quality | `best quality`；反向里那次「差劲的质量」是 `bad quality` |
| indicate detail | `intricate detail` |
| 盘体 / 绘画 | `painting` |
| 正题式词、正提示品 | 正向提示词 |
| 副题式词、附体词、复提示词 | 反向提示词 |
| 短剧、短片、细细脸 | 短语 |
| Laura | LoRA |
| Clip、转化层数 | CLIP 终止层数（CLIP skip） |
| 采样部数、迭代部署 | 迭代步数 Steps |
| 造点 | 噪点 |
| 提示词相关性 | CFG Scale |
| 闪子 | 骰子（种子随机） |
| 从位幅度 | 重绘幅度（Denoising strength） |
| 肉干缝 | 把图切成小块再补像素 |
| 抱险存 | 爆显存 |
| P 字、提价、清洗、进行成 | 批次、体现、清晰、高清修复后的图 |
| Strape Defusion | Stable Diffusion |
| 稍息 | 刷新 |
