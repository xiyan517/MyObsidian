# Stable Diffusion 基本介绍

> [!summary]
> 文生图走通一遍：选模型 → 按四段写提示词 → 调参数出小图 → **看中后固定种子，再开高清修复**。提示词用英文逗号分隔，可用括号调权重、竖杠 / AND 融合、方括号做步数切换。模型 / 插件各放各的文件夹。

![[02-txt2img-ui.png]]

---

## 1. 顶栏

| 控件 | 作用 | 怎么设 |
| --- | --- | --- |
| 大模型 | 定风格（写实 / 二次元…） | 下拉选择；新模型不出现就点刷新 |
| 外挂 VAE | 补细节、校颜色 | 有配套就选上 |
| CLIP 终止层数 | 提示词编码用哪一层 | 先留 **2** |

顶栏看不到 VAE / CLIP 时：设置 → 用户界面 → 快速设置填入，保存后重启 UI：

```text
sd_model_checkpoint, sd_vae, CLIP_stop_at_last_layers
```

---

## 2. 提示词

正向写要什么，反向写不要什么。反向用来卡住容易跑偏的元素：正向 `red hair`，反向可写 `black hair, white hair, purple hair`。

按四段写，之后加词知道该插哪一段：

| 段   | 写什么            | 例子                                                                       |
| --- | -------------- | ------------------------------------------------------------------------ |
| 全局  | 画质、风格          | `best quality, masterpiece, high resolution, intricate detail`           |
| 主体  | 人/物 + 特征，尽量用短语 | `a cute girl wearing a white sweater, smile, long hair, 1girl, red hair` |
| 场景  | 在哪里            | `nature, tree, grass`                                                    |
| 效果  | 光感、镜头          | `lens flare, cinematic`                                                  |

例如：

| 正向 | 反向 |
| --- | --- |
| `best quality` | `bad quality, low quality, normal quality` |
| `masterpiece` | `worst quality` |
| `high resolution` | `low resolution` |
| `intricate detail` | `simple detail` |

语法细则见文末「提示词的艺术」。

## 3. 模型

顶栏选大模型 / VAE；生成按钮下的中间按钮打开模型卡片（大模型、文本反转、LoRA、LyCORIS…）。

卡片太小看不清时：设置 → **附加网络**（Extra Networks，不同汉化名可能略有不同）→ 右侧选 **卡牌视图** → 保存 → 重启 UI。卡片变大方便认封面，但更容易挡住画面。

安装通法：文件丢进对应文件夹 → 回主页点 **刷新**。

![[02-model-folders.jpg]]

`models/Stable-diffusion` 里建子文件夹，刷新后卡片上会出现同名分类。

### 3.1 大模型（Checkpoint）

出图必用，定风格（写实 / 二次元 / 2.5D / 建筑…）。体积通常 **>1GB**。

| 步骤  | 做法                                 |
| --- | ---------------------------------- |
| 安装  | 放进 `models/Stable-diffusion`，刷新后点选 |
| 封面  | 出一张满意的图后，点当前模型位置，可用该图当封面，方便以后找     |

### 3.2 VAE

可看作大模型的附件，补光感、颜色纯度、细节。不是每个大模型都有外挂 VAE——很多已内置。有专属 VAE 时尽量用同名那份，效果通常更好；也可以拿别的模型的 VAE 试。

安装：拖进 `models/VAE` → 刷新。

### 3.3 文本反转（Embedding）

很轻，大约几十 KB，可搭配各种大模型；对画面影响也相对小。点封面后，名字会插入正向或反向提示词（看该模型属性）。

常见用法：用几个 Embedding **代替一长串负面词**，提示词更干净。例如减少坏手、代替「差劲质量」那堆词。

安装：放进 `embeddings`（或界面指定的文本反转目录）→ 刷新。

### 3.4 LoRA

给画面加指定细节 / 风格（卡通、二次元、机甲…）。风格不必和大模型完全同系，可以交叉试。

| 用法 | 说明 |
| --- | --- |
| 点封面 | 正向提示词里出现 `<lora:名字:权重>` |
| 权重 | 影响强度；数字越低影响越弱 |
| 触发词 | 下载页上找；有的有、有的没有，都能用 |
| 多个 LoRA | 可叠用混特征；**权重之和大约 ≤1**，否则容易过拟合、画面崩 |

安装：放进 `models/Lora` → 刷新。

### 3.5 LyCORIS

和 LoRA 很像，效果往往更好一点。用法相同：点封面进提示词、可改权重，可和 LoRA、文本反转一起用。

需先装插件（常见包名 `a1111-sd-webui-lycoris`、`LyCORIS`）：放进 `extensions` → 重启 →「扩展」里能看到名字。再把模型文件放进对应文件夹 → 刷新。

## 4. 生成参数

采样 = 从噪点一步步降噪成图。**步数**是降几次，**采样方法**是怎么降。

| 参数    | 怎么设                           |
| ----- | ----------------------------- |
| 迭代步数  | **30–50**（试稿 32，细化 40）。太低画面会怪 |
| 采样方法  | 见 §4.1                        |
| 宽 × 高 | 试稿 **512×512**；要照片感可加高        |
| 总批次数  | 想多看几张就加大（课上用 4）               |
| 每批数量  | 显存紧就留 **1**                   |
| CFG   | **5–15**，先留 **7**             |
| 种子    | 默认 **-1** 随机；骰子重置，绿色回收取上一张    |

有人脸可开 **面部修复**。要出大图再开 **高分辨率修复**。

### 4.1 采样器怎么选

![[02-samplers.png]]

![[03-sampler-recommend.png]]

| 需求 | 采样器 | 步数 |
| --- | --- | --- |
| 简单的图 | Euler（较快）、Heun | 正常步数 |
| 又快又好看 | DPM++ 2M Karras / UniPC | 20–30 / 30–60 |
| 质量优先 | DPM++ SDE Karras、DDIM（较快） | ≥15 |
| 稳，又想留点随机性 | Euler a、DPM2 a、DPM++ 2S a，以及带 Karras 的同名版 | 正常步数 |

日常试稿：`DPM++ 2M Karras`（20–30）或 `Euler`。要更精致换 `DPM++ SDE Karras`。想多变一点用名字带 **a** 的。

### 4.2 六类采样器

| 类 | 代表 | 特点 |
| --- | --- | --- |
| 最早一批 | Euler、Heun、LMS | 快；Euler / Heun 低步数就能看，**LMS 要更高步数** |
| 祖先采样器（名字带 **a**） | Euler a、DPM2 a、DPM++ 2S a，及对应 Karras | 每步加一点噪声 → 更随机；高步数也不易过拟合（过拟合 = 过度贴提示词导致崩坏） |
| 官方早期 | DDIM、PLMS | DDIM 适配 SD 1.0；PLMS 更快，但要更高步数才正常 |
| DPM 系列 | 名字带 DPM | 2022 为扩散模型出的，整体比老采样器强；其中 **DPM fast** 要高步数 |
| Karras | 名字带 Karras | 用噪声时间表控每步噪声水平，对画面控制更好 |
| 较新 | UniPC | 官方说 5–10 步就能高质量，实测仍要稍高步数 |

名字带 **a** 的那一组（Euler a、DPM2 a、DPM++ 2S a、DPM2 a Karras、DPM++ 2S a Karras）记成一类：稳，但 AI 还有发挥空间。

## 5. 高清修复

流程：小图试 → 看中后点绿色回收固定种子 → 开高清修复再生成。

![[02-upscalers.png]]

| 项 | 怎么设 |
| --- | --- |
| 放大算法 | 二次元 `R-ESRGAN 4x+ Anime6B`；写实 `R-ESRGAN 4x+` 或 `4x-UltraSharp` |
| 高清采样次数 | **15**（界面里 `0` = 沿用上面步数） |
| 重绘幅度 | **0.3–0.6**（太高会跑成另一张图） |
| 放大倍数 | **2** |

# Stable Diffusion 安装插件

插件丰富出图能力（抠图、精准控构图等）。装好后一般出现在**顶栏**或**参数区下方**；功能性插件也可能嵌在相关控件旁（课上比例插件：一键 1:1 / 3:2，小锁锁定宽高比）。

所有插件都在 WebUI 根目录的 `extensions` 里。

## 1. 三种安装方式

| 方式 | 步骤 |
| --- | --- |
| 扩展列表 | 扩展 → 可用 → **加载** → `Ctrl+F` 搜名字 → 安装 → **重启 UI** |
| GitHub 网址 | 仓库页复制链接 → 扩展 → **从网址安装** → 粘贴 → 安装 → 重启 |
| 手动文件夹 | GitHub 下载解压 → 把**插件本体文件夹**拖进 `extensions` → 重启 |

解压常有两层同名嵌套。若拖进去不显示，打开文件夹看是否还有一层同名目录，把**里层本体**放进 `extensions`。

## 2. 卸载

任选其一：

| 方式 | 注意 |
| --- | --- |
| 启动器 → 版本管理 → 扩展 → 右侧卸载 | 先**关掉正在跑的控制台**，再确认卸载 |
| 直接删掉 `extensions` 里对应文件夹 | 重启 WebUI 后生效 |

用网址重装时报错，多半是卸载后还有残留：按报错路径找到旧文件夹整夹删掉，再装一次。

## 3. 更新内核与插件

绘世启动器 → **版本管理**（界面顶栏可见「内核 / 扩展 / 安装新扩展」）。更新前先**关掉正在跑的控制台 / WebUI**。

![[01-launcher-extensions.png]]

### 3.1 更新内核（WebUI 本体）

| 步骤 | 做法 |
| --- | --- |
| 1 | 关掉控制台 |
| 2 | 版本管理 → **内核** |
| 3 | 按界面提示检查 / 更新到目标版本，完成后重新一键启动 |

内核和插件版本可能互相打架；插件异常时，可在内核页换几个版本试。

### 3.2 更新插件

版本管理 → **扩展**，列表里能看到插件名、远端地址、分支、版本 ID、更新日期。

| 方式 | 做法 |
| --- | --- |
| 单个更新 | 该行右侧点 **最新**（拉取当前分支最新提交） |
| 批量更新 | 右上角 **一键更新**（先刷新列表更稳） |
| 换旧版 / 指定提交 | 点 **切换版本**（仅 Git 安装的插件可用） |
| 启动器不奏效 | 到 GitHub 下最新包，**整夹替换** `extensions` 里旧目录 |

远端显示 **「非 Git 安装」** 的（如手动丢进 `extensions` 的包）：不能「切换版本」，也往往不能用「最新」在线拉。要更新就手动整夹替换。

WebUI 内也可以：扩展页 → **检查更新** → **应用并重启**（适合已能在扩展列表里识别的插件，如 ControlNet）。

## 4. 装了不显示 / 冲突

| 情况 | 怎么处理 |
| --- | --- |
| 文件夹放了但不出现 | 检查是否多嵌套一层；确认放的是插件本体 |
| 仍异常 | 换几个 WebUI 版本试（有的插件和当前版冲突） |
| 汉化打架 | 启动器 → 高级选项 → **不要勾选「启用云端汉化」**（和部分插件自带汉化冲突） |

## 5. 中英文提示词插件（Tags 自动填充）

不想每次打开「PNG 图片信息」再把整段参数送回文生图，可以用这款插件：**输入中文就能调出对应英文提示词**。

| 步骤 | 做法 |
| --- | --- |
| 装插件 | 插件文件夹放进 `extensions` |
| 放词库 | 打开插件里的 `tags`（或 Tags）文件夹，放入课程提供的中英文提示词 / 翻译文件 |
| 设词库 | 设置 → 左侧 **Tags 自动填充** →「词库文件」「词库翻译文件」都选刚放的文件（没有就点刷新） |
| 生效 | 保存设置 → 重启 UI → 提示词框即可用中文联想 |

### 自定义词库

词库文件大约有八万多词。用文本编辑器打开后：

| 想做的事 | 做法 | 效果 |
| --- | --- | --- |
| 加一组自己的词 | 新插一行，写关键词（如 `3D`），再写上相关英文 | 提示词里输入 `3D`，英文会弹出 |
| 改中文习惯 | 在已有中文后追加自己的说法（如在「笑」后加「开心」） | 输入「开心」也能弹出 `smile` |

改完保存，重启 UI（或按插件要求刷新）后再试。

## 6. Segment Anything（自动抠图）

要对画面**局部精准调整**（换裤子、改一件衣服等），装插件 `sd-webui-segment-anything`（资料包常见文件夹名 `sd-webui-segment-anything-master`）。

| 步骤 | 做法 |
| --- | --- |
| 装插件 | 把该文件夹放进 `extensions` → 重启 WebUI，下面能看到插件名 |
| 下模型 | 按显存选对应模型（资料里有），放到指定路径 |

### 标注与预览

1. 把要改的图拖进插件区。
2. **左键**点要抠的区域（黑点 = 要）；**右键**点不要的区域（红点 = 不要）。点错了再左键点同一处可取消。
3. 点 **预览**：会出三组蒙版，以及对应局部 PNG。
4. 用下面的 **0 / 1 / 2** 选最合适的那一组。

### 蒙版修边 → 送 ControlNet 换局部

1. 勾选「发送到 ControlNet / 重绘」相关选项。
2. 边缘毛糙：点下方柔化按钮，调边缘柔化尺寸 → **更新蒙版**。
3. 把图片 + 蒙版发到「上传蒙版」页；打开 ControlNet，**选与刚才 0/1/2 对应的那一路**（选了 1 就用 ControlNet 1）。
4. 预处理器和模型都选 **Inpainting**；调蒙版模糊、重绘幅度。
5. 出图宽高与原图**同比例**，最好 1:1 关系保持住。
6. 「上传蒙版」页**不用再手动上传图/蒙版**（ControlNet 已进后台）。在提示词写想换成的内容（如 `white pants`）→ 生成。

这样就能只改局部，其余不动。

## 7. ControlNet（重点）

用参考图的**图形特征**引导出图：预处理器抽出特征 → ControlNet 模型拿特征引导生成。可把场景改成夜晚、雪天，或锁住姿态、轮廓、深度等。

### 7.1 安装

| 方式 | 做法 |
| --- | --- |
| 已装过 | 扩展 → 检查更新 → 应用并重启 |
| 新装 | 插件拖进 `extensions` → 重启 UI |

还要下两样，缺一不可：

| 文件 | 放哪 |
| --- | --- |
| 预处理器模型 | 按资料里的对应关系，在指定目录**先建同名子文件夹**，再把模型放进去（直接扔根目录往往用不了） |
| ControlNet 模型 | 拖进 ControlNet 的 `models` 文件夹；配套的 `.yaml` 也要在（官网安装包通常自带） |

预处理器和模型下拉里都能选到，就说明装好了。

### 7.2 模型怎么读名

![[04-controlnet-naming.png]]

例：`control_v11p_sd15_openpose.pth`

| 段 | 含义 |
| --- | --- |
| `control` | 官方模型 |
| `v11` | ControlNet 1.1 |
| `p` / `e` / `u` / `f1` | 可正常用 / 实验中 / 未完成 / 曾有 bug 现已修复 |
| `sd15` | 搭配 SD 1.5 |
| `openpose` 等 | 功能名 |
| `.pth` | 权重；需和对应 `.yaml` 一起用 |

### 7.3 界面要点

| 控件 | 作用 |
| --- | --- |
| 启用 | 打开这一路 ControlNet |
| 低显存模式 | 显存紧时勾上 |
| 允许预览 | 勾上后出现爆炸图标，点它生成预览（代替旧版预览按钮） |
| 最佳像素 | 快速用最低可用分辨率；勾上后分辨率滑条会消失，按需开 |
| 分辨率滑条 | 低 → 预览粗；高 → 更细 |

控制强度三档（约等于旧版「提示词模式」一类开关）：

| 档 | 倾向 |
| --- | --- |
| 左 | ControlNet 与提示词差不多强 |
| 中 | 更听提示词 |
| 右 | 几乎完全跟 ControlNet |

多路：设置里把 ControlNet 数量调到 3（或更多）→ 保存 → 重启。常用叠法：OpenPose + Depth，或 Depth + Canny 补线。

### 7.4 各模型做什么

| 模型 | 提取什么 | 怎么用 |
| --- | --- | --- |
| Canny | 轮廓线稿 | 分辨率越高线越细；低阈值↑ 省略内部细节，高阈值↓ 线更多、更贴原图细节 |
| Depth | 空间远近 | 预处理器常见 Leres / Midas / Zoe。Zoe 轮廓与远近最稳；Leres 偏表面细节、空间弱。细节不够时用 Canny 补线叠用 |
| Inpaint | 涂抹区域局部改 | 类似图生图手绘蒙版，但改完的地方更易融进环境 |
| MLSD | 直线 | 室内、建筑结构 |
| Lineart | 线稿，细节保留度分档 | 不同预处理器还原松紧不同 |
| Lineart Anime | 二次元线条 | 高光、反光等二次元特征还原较好 |
| Normal（法线） | 表面凹凸 | 质感强；课上偏好的那个预处理器还原好，另一个易自由发挥 |
| OpenPose | 人体骨骼 / 脸 / 手 | 见下表。单靠 Pose **表情往往不够**，要生动表情需再叠 Lineart 等 |
| Scribble | 涂鸦线 | 线粗细、细节因预处理器而异；易丢肩颈空间，宜叠 Depth |
| Seg | 语义分割（按颜色分物体） | 人、车、建筑位置面积可控 |
| SoftEdge | 软边线（旧版 HED） | HED 组比 Pidinet 更稳；带 `safe` 后缀会过滤不良内容。细节与光影往往比 Canny 更全 |
| InstructP2P（IP2P） | 无预处理器 | 图直接拖入；提示词要短（如「晴天」「暴雨」）改场景状态 |
| Invert | 白底黑线 ↔ 黑底白线 | 预处理器 Invert，模型选 None，只做反色 |

OpenPose 预处理器细分：

| 预处理器 | 内容 |
| --- | --- |
| OpenPose | 骨骼 |
| OpenPose Face | 骨骼 + 脸 |
| OpenPose Hand | 骨骼 + 手 |
| OpenPose Full | 骨骼 + 脸 + 手 |
| OpenPose FaceOnly | 仅脸 |

已有现成骨骼图时：预处理器选 **None**，模型选 OpenPose，可开「更跟 ControlNet」那一档。

### 7.5 OpenPose Editor

扩展里搜 **OpenPose Editor** 安装。可上传图自动出骨骼再微调，或铺背景后手动摆点（眼、耳、鼻、胸、肩、肘、腕、胯、膝、踝；**腕点不要摆到手指**）。导出 PNG → 丢进 ControlNet 用。

# 提示词的艺术

CLIP 把文字和图像对齐，从而读懂提示词。顶栏 **CLIP 终止层数**（跳过层）默认 **2**：编码器共约 12 层，跳过最后 2 层、用前 10 层理解。跳太多，理解不充分，效果会差。语法必须用**英文标点**。

## 1. 基础：逗号与词序

- 词与词之间用**英文逗号**；中文逗号不被识别。
- **越靠前权重越高**。例：`flower` 放在 `cat` 前，花更容易进画面；效果约等于给花 `(flower:1.3)`。

## 2. 加减权重

| 写法 | 作用 |
| --- | --- |
| `(word)` | ×1.1；可叠层 `((word))` = ×1.1² … |
| `(word:1.3)` | 指定倍数 |
| `[word]` | 降权；可叠层，影响力变小 |

权重主要影响该词在画面里的**面积 / 存在感**。拉太高会出现**语义污染**：相关属性全涌进来（花 → 多品种、多颜色；水 → 水珠、涟漪、洒水器）。权重一般 **不要超过 2**，再高（如 5）画面易废。

## 3. 交替融合：`|` 与 `AND`

| 写法 | 含义 |
| --- | --- |
| `cat\|peacock` | 每隔一步换一个词画（步数 = 采样步数）。32 步则各约 16 次，易融出新物种 |
| `A AND B` | 也是交替融合，但饱和度更高，更易过拟合（色彩发脏、形状夸张） |

融合物最好有**形态相似**（香蕉↔蛇），狗↔香蕉往往融不好。可再单独给某一侧加权重。`AND`：**UniPC、DDIM 不支持**。

## 4. 按步数切换 / 延迟

![[05-prompt-switch.jpg]]

| 写法 | 含义（总步数 32 时） |
| --- | --- |
| `[panda:human:10]` | 前 10 步画 panda，后 22 步画 human |
| `[dragon:tiger:0.7]` | 前 70% 步龙，后 30% 虎（小数 = 比例） |
| `[flower:17]` | 第 17 步之后才开始画花（延迟出现 ≈ 变相降权） |
| `[river::10]` | 仅前 10 步画河，之后不再画（前段形状可能被后段改成路等） |

`[from:to:when]` 里**不能再给词加权重**，可玩性少一点。微调时：改数字后点种子旁**绿色回收**，固定上一张构图再比。
