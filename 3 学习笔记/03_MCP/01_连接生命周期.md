# MCP 连接生命周期

> [!summary]
> MCP 客户端与服务器的一次完整连接分五步：**发现 → 初始化 → 能力交换 → 活跃会话 → 终止**。课例用 Claude（Client）连接 GitHub MCP Server，经 **stdio** 建连、交换 Tools / 能力，再调用 `list_repo`、`get_file`，最后主动断开。

前置概念：[[00_MCP基础]]

## 1. 五步总览

| 顺序 | 步骤 | 英文 | 做什么 |
| --- | --- | --- | --- |
| 1 | 发现 | Discovery | 从客户端配置里找到目标 MCP Server |
| 2 | 初始化 | Initialization | 启动与 Server 进程的连接（常见为 stdio） |
| 3 | 能力交换 | Capability Exchange | 双方声明各自能力（Tools / tool calls 等） |
| 4 | 活跃会话 | Active Session | 真正通信：列工具、调工具、拿结果 |
| 5 | 终止 | Termination | 用完后结束连接 |

课例角色：

| 角色 | 是谁 |
| --- | --- |
| Client | Claude |
| Server | GitHub MCP Server |

---

## 2. 发现与初始化

### 2.1 Discovery

Claude 有一份**配置文件**，列出它可访问的全部 MCP Server。连接时从中查找 **GitHub MCP Server**。

### 2.2 Initialization（stdio）

找到 Server 后初始化连接：启动到 GitHub Server 进程的 **stdio**（标准输入输出）通道。

```text
Claude（Client）──写入──▶ Server 的 stdin（server input）
Claude（Client）◀──写出── Server 写到客户端侧输出
```

交换初始消息后，连接建立，进入能力交换。

---

## 3. 能力交换（Capability Exchange）

### 3.1 Server 声明 Tools

GitHub MCP Server 声明自己提供的工具（名称即功能）：

| Tool | 作用 |
| --- | --- |
| `create_issue` | 创建 GitHub Issue |
| `list_repo` | 列出某 GitHub 账号下的仓库 |
| `get_file` | 返回指定文件内容 |

### 3.2 Client 声明能力

Claude 回复自己的能力，例如：

- 支持 **tool calls**（可对有权访问的工具发起调用）
- 支持 **resource access**（资源访问）

双方能力对齐后，会话就绪，进入活跃通信。

---

## 4. 活跃会话（Active Session）

典型调用链（课例）：

```text
Claude
  │  list available tools
  ▼
GitHub MCP  →  create_issue / list_repo / get_file
  │
  │  call list_repo(user=Anthropic)
  ▼
GitHub MCP  →  JSON：该账号下仓库列表
  │
  │  选定仓库 Claude MCP
  │  call get_file(repo=Claude MCP, ...)
  ▼
GitHub MCP  →  返回文件内容
  │
Claude 拿到内容，任务完成
```

要点：

1. 先 **list tools**，确认 Server 上有哪些可调用工具  
2. 再按需 **call tool**（如按用户 `Anthropic` 列仓库）  
3. Server 处理请求，常以 **JSON** 返回结构化结果  
4. Client 根据结果继续决策（选仓库 → 再调 `get_file`）

---

## 5. 终止（Termination）

Claude 已拿到所需文件内容后：

1. Client 通知 Server：**终止连接**  
2. Server 结束连接  
3. 本次 MCP 连接生命周期结束  

---

